# 🚀 Interactive AI Portfolio & Resume

An interactive, modern, and single-page personal portfolio website designed for Computer Vision and Deep Learning specialists. Built with HTML5, CSS3 (Glassmorphism UI), and Particles.js for an interactive neural-network background.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![GitHub Pages](https://img.shields.io/badge/deploy-GitHub%20Pages-brightgreen.svg)

---

## ✨ Features

* **Interactive AI Neural Network Background**: Full-page 3D particle network powered by `Particles.js` that reacts to mouse movement.
* **Glassmorphism Design**: Modern semi-transparent card layout with dark mode background (`#0f172a`).
* **Fully Responsive**: Optimized for all viewports from mobile devices to high-resolution desktops.
* **Smooth Scrolling & Animations**: Interactive entrance screen with subtle floating and fade-in animations.
* **Clean & Modular CSS**: Easily customizable colors, layout, and content.

---

## 🛠️ Built With

* **HTML5** & **CSS3**
* **Particles.js** (Interactive Background)
* **Font Awesome v6** (Icons)
